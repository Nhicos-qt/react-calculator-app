# React Calculator App

A fully functional calculator web application built with React and Tailwind CSS.

## Features

- **Calculator Interface**: Clean, responsive design with number buttons 0-9
- **Arithmetic Operations**: Addition, Subtraction, Multiplication, Division
- **Advanced Functions**: Clear (C), Delete (DEL), Percentage (%), Decimal support
- **Error Handling**: Division by zero detection with error message
- **Keyboard Support**: Full keyboard input support for numbers, operators, and functions
- **Real-time Display**: Shows current calculation and results instantly
- **Responsive Design**: Works perfectly on mobile, tablet, and desktop devices
- **Interactive UI**: Hover effects, button animations, and smooth transitions

## How to Use

1. Enter numbers using the on-screen buttons or your keyboard
2. Select an operator (+, -, *, /) to perform arithmetic
3. Press = to calculate the result
4. Use C to reset the calculator
5. Use DEL to remove the last digit

## Installation

```bash
npm install
```

## Development

```bash
npm run dev
```

## Build for Production

```bash
npm run build
```

## Preview Production Build

```bash
npm run preview
```

## Deployment

This app is ready to deploy on Vercel:

1. Push the code to GitHub
2. Import the repository in Vercel
3. Vercel will automatically detect Vite and build the app
4. Your app will be live at `https://your-app-name.vercel.app`
